# ADR-0003：导航与应用壳层

状态：Accepted。日期：2026-10-18。

## 背景
两个模板面向相似业务场景，但分别采用侧边栏和顶部导航布局。布局应形成清晰差异，同时保留相同业务模型和主要交互。

## 决策
- 桌面端使用左侧分组侧边栏，支持展开和仅图标折叠。
- 窄屏使用 Drawer 导航。
- 保留应用内页面标签；标签支持关闭，刷新恢复属于当前会话的标签状态。
- 采用专业蓝色视觉基调。

共同要求：路由、菜单、面包屑、页面标题尽可能由集中路由元数据派生；窄屏导航必须可操作；主题首次访问跟随系统、手动选择后保存；布局差异不得改变业务 API、实体模型或 DataTable 契约。两个仓库不共享运行时 UI 包或源代码。
